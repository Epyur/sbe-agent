# LogicTEAM.007 (sbe-agent)

Универсальный LLM-агент: MCP-набор инструментов (создание/чтение Word/Excel/JSON/электронных
PDF), чтение баз данных (письма, документы, ЛИМС) по правам пользователя и локальной базы
задач. Файлы генерируются на сервере и выдаются ссылкой на скачивание (~2 дня).

## Требования

- Установлены и включены: `sbe-apstore` (ЦУП СБЕ ПМиПИР), `sbe-llm` (LLM-центр).
- Права на чтение данных — как в соответствующих плагинах («Письма», «Документы»,
  «Заявки на испытания»/«ЛИМС»); сервер проверяет JWT пользователя.

## Использование

Откройте плагин через ЦУП СБЕ ПМиПИР → «Установленные» → «Открыть» (у sbe-agent
собственных риббона и команд нет).

## Возможности

- **Чат с агентом**: задавайте вопросы на русском; агент сам решает, какие инструменты вызвать.
- **Создание файлов** (на сервере, ссылка на скачивание ~2 дня): Word (.docx), Excel (.xlsx),
  PDF (электронный), JSON — по структуре из запроса.
- **Чтение файлов**: прикрепите файл в чате (docx/xlsx/pdf/json) — агент извлечёт содержимое.
- **Доступ к данным по правам**: письма (поиск по теме/автору/направлению), документы,
  заявки ЛИМС, локальные задачи.
- **Контекст пользователя**: имя из настроек + email из ЦУП; доступные источники показаны
  в сайдбаре с уровнем роли.
- **История диалогов** сохраняется в `yourbase/sbe_agent/chat_history.json`.
